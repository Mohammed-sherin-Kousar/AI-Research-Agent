# AI Research Agent

##  Project Overview

Developed an **AI Research Agent** to automate a basic research workflow from topic selection to report generation. The system retrieves relevant information from a structured knowledge base, processes the retrieved information, generates a summary, and saves the final research report.

##  Objective

* Automate a basic research workflow.
* Retrieve relevant information from a knowledge base.
* Generate concise research summaries.
* Create structured research reports.
* Demonstrate **Agentic AI and tool-calling concepts**.

##  Technologies Used

* Python
* LangChain
* OpenAI
* Pandas
* CSV
* Google Colab

##  Key Steps

* Prepared a structured research knowledge base using CSV files.
* Developed a custom **Search Tool** to retrieve relevant information.
* Developed a **Summarization Tool** to process retrieved information.
* Developed a **Save Report Tool** to generate Markdown reports.
* Connected the tools through a tool-calling workflow.
* Tested the research workflow with different topics.
* Generated and saved research reports.

##  Architecture / Approach

* Used an **LLM-based agent workflow** to coordinate the research process.
* Implemented a **Search Tool** for retrieving information from the local knowledge base.
* Implemented a **Summarization Tool** for generating concise summaries.
* Implemented a **Save Report Tool** for creating Markdown reports.
* Used **tool calling** to connect and coordinate the available tools.
* Followed the workflow:

```text
Research Topic
      ↓
Search Tool
      ↓
Knowledge Base
      ↓
Summarization
      ↓
Research Report
      ↓
Markdown File
```

##  Result

* Successfully retrieved relevant information from the structured knowledge base.
* Generated concise summaries from retrieved information.
* Automatically created structured research reports in Markdown format.
* Demonstrated an end-to-end **Agentic AI research workflow** using multiple tools.
